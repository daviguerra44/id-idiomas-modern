# ID Idiomas — Nova experiência

Site responsivo em HTML, CSS e JavaScript, sem dependências de execução.

Inclui catálogo filtrável de cursos, detalhes em modal, metodologia, história, vídeo, ID Connector, Star Event, e-books, blog e demonstração navegável do My ID.

## Limites da versão

- My ID é uma demonstração explicitamente identificada, sem autenticação real ou dados privados. O nome de exibição é salvo apenas no navegador.
- Materiais oficiais, blog e eventos são acessados nos endereços da escola.
- Integração com matrículas, autenticação e biblioteca restrita depende da API ou do código do sistema existente.
- A foto de estudantes é ilustrativa, fornecida pelo Unsplash. Logomarca e vídeo são do site oficial.
- O servidor pode servir a pasta `dist` diretamente.
