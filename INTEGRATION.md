# Integração do MyID original

O portal informado é http://my.id-idiomas.com.br. A página pública usa um formulário POST para /login/authenticate e exige uma sessão para abrir o perfil e os cursos. A inspeção pública não revelou uma API documentada de aulas ou PDFs. Não foi possível inspecionar endpoints autenticados nesta sessão: o host de controle do navegador não estava disponível e nenhuma conexão com o Opera foi exposta às ferramentas. Não foram coletados senhas ou cookies do navegador.

A plataforma nova permite importar múltiplos PDFs, um por aula, com título editável; também permite adicionar vários PDFs a uma mesma aula e registrar sua data e ordem. Arquivos são protegidos pelo usuário autenticado no Sites. Os vídeos públicos da comunidade foram desvinculados das matrículas automaticamente, preservando dados pessoais, notas e cadastros.

Para sincronização automática real, é necessário acesso autorizado à sessão original por uma ferramenta conectada ou à documentação/API do fornecedor. Apenas o endereço do perfil não fornece os arquivos restritos. Não foram criados PDFs, aulas ou registros de presença fictícios.
